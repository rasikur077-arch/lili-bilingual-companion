# Lili Bilingual Companion

Build a beautiful mobile-first personal AI assistant web app named LILI AI.



Design:



- Premium futuristic interface.

- Dark navy and purple theme.

- Beautiful friendly AI avatar in the center.

- Smooth animations.

- Chat bubbles with rounded corners.

- Clean and modern Android mobile layout.



Features:



1. Chat interface.

2. Text input and send button.

3. Voice input button with microphone icon.

4. AI response area.

5. Chat history.

6. Settings page.

7. Personalization settings.

8. Responsive design for Android phones.



Personality:

Lili is a friendly, intelligent and helpful personal AI assistant. She communicates in natural Bangla and English.



IMPORTANT:

Create a functional frontend prototype first. Do not pretend that AI responses work until a real AI model is connected. Do not expose API keys in frontend code.
